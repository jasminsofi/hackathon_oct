# 🚀 CampusFlow - CTRL+CINCO

## 📋 Descripción del proyecto  
CampusFlow es una aplicación desarrollada colaborativamente por un equipo de 5 integrantes. Fue diseñada utilizando **Python y Flask** (con HTML y Bootstrap en el frontend) para optimizar la gestión de recursos y actividades de Campuslands. 
Su objetivo es centralizar la información de las aulas, el préstamo de equipos tecnológicos y el registro de incidencias, facilitando la organización, la gestión de estados y la toma de decisiones. 
El proyecto incorpora un componente de Inteligencia Artificial asistida por reglas y análisis de datos.

## 🎯 Objetivos  
1. **Optimizar la gestión de espacios:** Facilitar la consulta y el control de disponibilidad de aulas sin solapamientos ni conflictos de aforo, potenciado por recomendación inteligente.
2. **Mejorar el control de los recursos tecnológicos:** Implementar un sistema de registro y seguimiento de los préstamos, devoluciones y trazabilidad de estado de los equipos.
3. **Agilizar la gestión de incidencias:** Permitir el registro, clasificación, priorización y enrutamiento automatizado.
4. **Integrar inteligencia artificial funcional:** Aprovechar el motor lógico interno para sugerencias automáticas sin depender de internet o API keys pesadas.
5. **Garantizar la integridad de la información:** Incorporar validaciones estrictas de negocio mediante datos locales estructurados.
6. **Promover una gestión eficiente:** Centralizar datos oficiales para respaldar la toma de decisiones con alta coherencia operativa.

## ⚙️ Funcionalidades Principales

🏫 **Gestión de aulas**
Permite administrar y consultar la información de las aulas del campus, incluyendo sus características, disponibilidad, capacidad, recursos y estado, facilitando la organización y el aprovechamiento de los espacios académicos.

💻 **Gestión de equipos tecnológicos**
Facilita el control de los equipos tecnológicos del campus mediante la administración de su disponibilidad, préstamos, devoluciones y estado, manteniendo un registro de sus movimientos para mejorar el seguimiento de los recursos.

🚨 **Gestión de incidencias**
Permite registrar, clasificar y realizar seguimiento a las incidencias presentadas en el campus, facilitando su priorización, asignación y resolución mediante el control de su estado y la información relacionada con cada caso.

📊 **Panel de control y reportes**
Centraliza la información relevante del campus mediante indicadores y reportes que permiten consultar el estado de las aulas, los equipos y las incidencias, facilitando el análisis de la situación actual y la toma de decisiones.

🤖 **Inteligencia artificial**
Integra herramientas de inteligencia artificial para analizar la información disponible del sistema, responder consultas contextualizadas, identificar patrones y generar recomendaciones que contribuyan a resolver problemas y optimizar la gestión del campus.

## 🛠️ Stack Tecnológico
- **Backend:** Python, Flask
- **Frontend:** HTML5, Bootstrap, CSS
- **Inteligencia Artificial:** Motor lógico de reglas en Python (Sin coste de API, offline-ready)
- **Datos:** Archivos JSON locales (`data/aulas.json`)
