# 🚀 CampusFlow - CTRL+CINCO

## 📋 Descripción del proyecto  

El Sistema Central de Gestión Operativa es una aplicación web desarrollada para optimizar la administración de espacios dentro de Campuslands. La solución permite gestionar la disponibilidad de aulas, realizar reservas y garantizar el cumplimiento de reglas de negocio que eviten conflictos de horario y problemas de capacidad.

El objetivo principal es ofrecer una herramienta sencilla, funcional y confiable para la asignación de espacios, manteniendo la integridad de la información y mejorando la organización de los recursos disponibles.

## 🎯 Objetivos  
1. **Optimizar la gestión de espacios:** Facilitar la consulta y el control de disponibilidad de aulas sin solapamientos ni conflictos de aforo, potenciado por recomendación inteligente.
2. **Mejorar el control de los recursos tecnológicos:** Implementar un sistema de registro y trazabilidad de estado de los equipos.
3. **Garantizar la integridad de la información:** Incorporar validaciones estrictas de negocio mediante datos locales estructurados.
4. **Promover una gestión eficiente:** Centralizar datos oficiales para respaldar la toma de decisiones con alta coherencia operativa.

## Tecnologías Utilizadas

- Python 3
- Flask
- Bootstrap 5
- HTML5
- JSON
- Git y GitHub

## ⚙️ Funcionalidades Principales

🏫 **Gestión de aulas**
Permite administrar y consultar la información de las aulas del campus, incluyendo sus características, disponibilidad, capacidad, recursos y estado, facilitando la organización y el aprovechamiento de los espacios académicos.

💻 **Gestión de equipos tecnológicos**
Facilita el control de los equipos tecnológicos del campus mediante la administración de su disponibilidad, préstamos, devoluciones y estado, manteniendo un registro de sus movimientos para mejorar el seguimiento de los recursos.
